# Imagens do Nowfood

Coloque nesta pasta a logo e as fotos usadas no app.

A logo utilizada nas telas fica em `logo.png`. As imagens de categoria, promoção e login também ficam nesta pasta.

Para usar uma imagem local em uma tela React Native:

```tsx
<Image source={require('../../assets/minhas-imagens/nome-da-imagem.png')} />
```

O caminho relativo pode variar conforme a pasta da tela.
